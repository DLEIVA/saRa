# saRa 1.0.0: jamovi library acceptance checklist

The source is a candidate. The old generated R headers must be regenerated by jmvtools. No corrected .jmo is supplied yet.

1. In the saRa source directory run `source("audit/VALIDATE_IN_R.R")` in an R session configured for your installed jamovi. Save the complete console log. Stop and fix any compiler, dependency, or test failure.
2. Confirm the generated .jmo installs into the target jamovi version and launches after restarting jamovi. Record jamovi, its embedded R, jmvtools and dependency versions, and retain complete build/test logs. `R CMD build` and `R CMD check` are optional supplementary R-package diagnostics, not CRAN submission steps or substitutes for jamovi validation.
3. Numerical and mixed summaries: values 1, 10, 100 must give geometric mean 10 and geometric SD 10. Try non-positive, all-missing, single-observation, and constant columns. Constant histograms must not crash.
4. Ordinal summaries: stored values 0–4 must stay 0–4; 1, 2, 5 must retain 5. With 0:4, a 90% inner range is 3.6, while 50% is 2. Test numeric-backed and text-labelled ordered variables. Do not release if text-labelled ordinal conversion loses order or the UI rejects legitimate ordinal data.
5. Categorical and ordinal associations: perfect positive/negative 2×2 association must give ±1 for Yule’s V and Wilson’s e. A perfect 3×3 diagonal must give Chuprov’s T = 1. Check single-level and empty contingency tables.
6. Wilcoxon: compare against `wilcox.test(..., paired=TRUE)`. Include zero differences, ties, all ties, empty pairs, two pairs whose variables are not the first columns, and both missing-value modes. Change confidence width to 90 and 99. Confirm median-CI variable labels and the three-row descriptives layout.
7. Mann–Whitney: use unequal group sizes and tied observations. Compare z p-values against `wilcox.test(..., exact=FALSE, correct=FALSE)` for each alternative. Check empty groups after missing-value exclusion.
8. Normality: select only K–S on >5,000 observations, then select Shapiro–Wilk and verify a cell footnote. Test group sizes 2, 4 and 7, missing values, constant variables, two dependent variables, and a single observed grouping level. Ensure unselected tests do not execute and rows do not overwrite each other.
9. ECDF/Q–Q: use groups with distinctly different ranges, interleave their rows, then insert missing values. Confirm each facet retains its group and standardises within that group.
10. Distributions: hypergeometric m=1,n=10,k=1; population of one; geometric and negative-binomial p=1; invalid p=0; excessive draws; zero Poisson rate; fractional typed discrete values; non-positive continuous scale/df/rate and reversed uniform limits. Check all plot styles and probability endpoints.
11. Bivariate plots: rename columns to “Age group”, “Q1 score”, “1st measure” and a name containing a backtick. Check bar, mosaic, heatmap, alluvial, scatter and every marginal-plot style.
12. Result visibility: select only Cramér’s V, only τ, only Theil’s U, and each ordinal association separately. Change variables and CI options; check stale results and clearWith behaviour.
13. Switch stacked dotplots on. Check central-tail continuous quantile plots. Confirm box-fence controls remain enabled for box/violin plots.
14. Confirm references display correctly, help descriptions match defaults, and labels are readable. Review the Q–Q appearance following consolidation into the internal helper.
15. Save, close and reopen an .omv containing all plot types. Export HTML and PDF. Recheck after changing variables and group selection. Verify exported plots and references survive.

## Regression follow-up

1. Restart jamovi after rebuilding. Open built-in Linear Regression with no variables: no saRa error should appear.
2. Select a dependent variable alone, then add covariates/factors. Check no stale tables or errors.
3. Select Normality test: show the three saRa normality tests, RESET and four heteroskedasticity tests; the parent single Shapiro–Wilk table is hidden to avoid duplication. Deselect it: additional tables disappear.
4. Select Autocorrelation test with Normality test off: retain Durbin–Watson and show the ACF independently.
5. Add a second model block: diagnostics/plots correspond to each fitted model. Change variables, blocks, weights and data; verify updates.
6. Check short, constant, missing and singular data: no add-on crash; unavailable diagnostics display explanations.
7. Export HTML/PDF and save/reopen .omv: ACF renders identically. Use observations in meaningful sequence for autocorrelation interpretation.

## Expanded Regression acceptance checks

- Normality: confirm three saRa tests plus RESET; KS explicitly says Lilliefors. Check small/constant residual samples show unavailable cells rather than crashes.
- Heteroskedasticity: confirm four rows, titles, attribution and GQ/HMC ordering/simulation notes. Compare directly with documented lmtest calls.
- Autocorrelation: confirm lag 1 through 10 (or N-1), DW/bootstrap note with 5,000 and 123456, and reproducible results when reopening the same analysis. Row order must match observation sequence.
- ACF: confirm short caption is visible and contains the saRa note, Lag axis label is separate, no duplicate internal title, automatic lag count.
- Residual plots: confirm all four additional plots appear with attribution, Q-Q histogram inset is readable, influence table matches top-two union and original fitted-row labels.
- Compare influence numbers with car::influencePlot on the same model; ensure omitted cases are not relabelled sequentially.
- Multi-model, missing, weighted and singular cases; toggle all three controlling checkboxes off/on and change data/weights.
- Export all plots to HTML/PDF and save/reopen .omv.
- For a clean comparison, temporarily turn off the moretests add-on through jamovi's module UI if its overlapping tables are still displayed.
